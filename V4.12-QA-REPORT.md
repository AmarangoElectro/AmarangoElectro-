### Standalone Android

- Archivo: `AmarangoElectro-V16-V4.12-Standalone-Android.html`.
- SHA-256: `c00a02bc9056947e56bd7325e60b477ea8b03161b2bc788869179d5e9e1fc068`.
- Abre directamente y no contiene iframe.
- Los datos están embebidos como fixture público sanitizado; las fotografías conservan URLs HTTPS de solo lectura.
- Favoritos usan únicamente `localStorage` del dispositivo.
- Compartir usa `navigator.share` o clipboard, sin llamadas al catálogo.
- La ficha usa hash local estable (`#producto-product-nNNN` / `#producto-product-pNNN`).

La comprobación visual con el navegador cloud no pudo ejecutarse porque su política bloquea URLs locales `file://`. No se intentó evadir esa restricción ni publicar el archivo. El responsive sí quedó cubierto por el contrato automatizado y el HTML se entrega para apertura directa en Android; el smoke visual en un dispositivo físico queda recomendado como revisión humana, no como PASS visual inventado.
