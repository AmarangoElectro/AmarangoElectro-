## Cambios realizados

- Se creó un contrato explícito por categoría para diferenciar `embedded` (arte con texto integrado) de `background` (fondo con copy HTML).
- Los ocho artes oficiales conservan su proporción real 4:3, sin zoom ni crop al pasar el cursor.
- Las otras catorce categorías usan fondos individuales 3:2, sin texto ni logos rasterizados, con copy accesible como capa de interfaz.
- Se generaron variantes mobile 768 px de cada banner sin cambiar el encuadre.
- Se mantuvo una sola capa visible del logo; el asset usado conserva transparencia real.
- Se agregó carga diferida para las categorías fuera del primer tramo y prioridad alta solo para las dos primeras.
- Se agregó una regresión automática que valida cantidad, unicidad, peso, formato, relación de aspecto, separación de modos y ausencia de escrituras.
- Se restauraron dos previews administrativos históricos, byte a byte desde el checkpoint Step 7R.1, porque el ZIP V4.9 no los incluía aunque tres tests existentes los requerían. No se modificó lógica administrativa.

## Bugs encontrados y corregidos

1. La grilla anterior no tenía una biblioteca individual completa para las 22 categorías.
2. Un único supuesto 3:2/`cover` podía recortar artes 4:3 con texto integrado.
3. El componente superponía logo y copy HTML incluso cuando el arte ya los contenía.
4. El ZIP V4.9 omitía dos previews offline requeridos por tres tests históricos.
