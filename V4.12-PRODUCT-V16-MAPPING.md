# V4.12 — Real Catalog → Product V16 Mapping

## Contrato

```text
RealCatalogSource
  └─ CanonicalCatalogAdapter (server/read-only + fail-closed + allowlist)
       ├─ Product V16 público/comercial
       └─ AdminCatalogExtension autorizada
```

Un solo Product V16 alimenta Cliente, Asesor y Administración. Administración puede adjuntar una extensión interna por `stableId`; no se crea un catálogo independiente.

## Product V16 mínimo

| Product V16 | Fuente real V4.12 | Regla |
|---|---|---|
| `stableId` | master `id` / incremental `producto_id` | string numérico persistente |
| `slug` | `stableId` | `product-nNNN` o `product-pNNN` |
| `name` | `nombre` | obligatorio |
| `brand` | no hay campo canónico | derivación conservadora por token con provenance; si no, null conceptual |
| `model` | no comprobado | `null` |
| `memory` | no comprobado en master | `null` |
| `category` | `categoria` | mapeo explícito a universo V16 |
| `subcategory` | `categoria` | mapeo explícito cuando corresponda |
| `image` | `foto` | solo HTTPS; si no, null |
| `images` | `foto` | `[image]`; arrays internos de duplicados no se publican |
| `cashPriceARS` | `venta` | finito y >0 |
| `financing` | no existe política auditada | `[]` |
| `availability` | stock/provider state | available/unavailable/unknown exacto |
| `visibility` | master + incremental + overlays | fail-closed |
| `updatedAt` | incremental `actualizado` | timestamp del read model |

## Clasificación por rol

### Público cliente

`stableId`, `slug`, `name`, `brand` cuando sea confiable, `model`, `memory`, categoría/subcategoría normalizadas, imagen, precio contado, financing auditada (vacía en V4.12), availability, descripción/características públicas.

### Comercial asesor

Mismo Product V16 público. No se encontró un campo asesor-only auditable dentro del master. Cuotas no se calculan en este gate.

### Interno administración

Costo, mayorista/proveedor, stock numérico, precio/origen proveedor, conversión USD, metadata de revisión/sync/duplicados.

### Nunca exponer frontend público

Raw JSON, costo, mayorista, proveedor IDs/códigos/claves, moneda/precio proveedor, USD/cotizaciones, `_pj`, metadata de lock/sync, hashes/credenciales si existieran.

## Reglas de publicación del parser V4.12

El módulo `lib/catalog/v412-source-contract.ts` implementa una función pura `evaluateV412Publication` para congelar estas invariantes:

- stableId obligatorio;
- envelope incremental obligatorio en el gate de lectura versionada;
- IDs master/incremental deben coincidir;
- tombstone bloquea;
- `visible` debe ser exactamente `true`;
- nombre/categoría/precio válidos;
- ocultamientos explícitos bloquean;
- stock explícitamente agotado bloquea el piloto;
- overlay `visible=false` bloquea;
- stock desconocido permanece `unknown`.

## Snapshot V4.12

`V4.12-SANITIZED-SNAPSHOT-25.json` es una proyección allowlist de 25 productos. `lib/catalog/v412-canonical-adapter.ts` la valida con Zod y produce un `V412CanonicalProduct` que extiende el Product actual sin activar el catálogo principal.
