# V4.15.3 — Brechas exactas antes de producción

Esta lista incluye **toda función que no alcanzó PRESERVADA**. No autoriza su conexión ni escritura.

## catalog

- **Cargar / actualizar catálogo — PARCIAL:** Preserve paste workflow: Costo / Venta / USD, category, features, supplier and optional photo; add mandatory preview.
- **Subir todo a la nube — PENDIENTE:** Replace frontend publish with explicit server-side authorized commit.
- **Editar producto — PARCIAL:** Name/category/features/supplier/cost/sale and controlled fields.
- **Categorías / categoría proveedor / reclasificar Otros — PENDIENTE:** Preserve manual category override and supplier restore.
- **Marcar varios / mostrar / ocultar — PARCIAL:** Bulk operations with preview + audit.
- **Ocultar / mostrar categoría — PENDIENTE:** Bulk category visibility command.
- **Ver favoritos — PENDIENTE:** Preserve Admin shortcut/filter for favorited products.
- **Reemplazar todo el catálogo — PENDIENTE:** Preserve Legacy option but classify as high-risk; full diff, backup and explicit confirmation required.

## phones

- **Cargar / actualizar celulares — PARCIAL:** Preserve PESOS/USD modes, name+price line formats, update existing, add new, missing-item decision, brand ordering and metadata preservation.
- **Actualizar dólar sin pegar nada — PARCIAL:** Reprice phones carrying original USD without repasting; preview before commit.
- **Cargar características de celulares (masivo) — PENDIENTE:** Preserve block paste + name matching; ambiguous matches require review.
- **Banco permanente de fotos de celulares — PENDIENTE:** Photos follow canonical model across list refreshes; secure Storage later.
- **Borrar toda la lista de celulares — PENDIENTE:** Soft-delete / trash with explicit confirmation and audit.
- **Borrar celulares por marca — PENDIENTE:** Preserve by-brand operation; trash + audit.
- **Resolver celulares que ya no vienen en la lista — PENDIENTE:** Preserve choices: dejar / sin stock / papelera; never choose automatically.
- **Aviso de coherencia de memoria/precio — PENDIENTE:** Warn if higher-memory variant is priced equal/lower; never auto-edit.
