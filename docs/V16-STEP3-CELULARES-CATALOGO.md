# AmarangoElectro V16 — Step 3 (Celulares / Catálogo)

## Objetivo
Profundizar la categoría Celulares y unir mejor la experiencia visual de marca con el explorador de catálogo.

## Cambios incluidos
- Nuevo bloque `catalog-brand-stage` dentro del catálogo de Celulares.
- Presentación dinámica según marca activa:
  - Todos
  - Apple
  - Samsung
  - Motorola
  - Xiaomi
  - Infinix
- Nueva grilla de acceso rápido a marcas dentro del catálogo.
- Barra de filtros activos con acción `Limpiar`.
- Sincronización de filtros a URL:
  - `?marca=`
  - `?q=`
  - `?orden=`
- Mejor lectura visual del estado actual del explorador.
- Responsive desktop + mobile.
